# 🚀 Tesla Stock Price Prediction

A machine learning and deep learning based web application that predicts Tesla stock prices using historical market data. The project is built with Python, TensorFlow, Scikit-Learn, and Streamlit, providing an interactive interface for users to explore stock trends and predictions.

## 🌐 Live Demo

🔗 Streamlit App: [https://tesla-price-prediction.streamlit.app](https://tesla-price-prediction.streamlit.app)

## 📂 GitHub Repository

🔗 Repository: https://github.com/yashprajapati18705-ctrl/Tesla-price-Prediction

## 📌 Features

- Historical Tesla stock data analysis
- Data preprocessing and feature engineering
- Interactive visualizations
- Deep Learning model using TensorFlow/Keras

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yashprajapati18705-ctrl/Tesla-price-Prediction.git
cd Tesla-price-Prediction
````

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Environment

#### Windows

```bash
.venv\Scripts\activate
```

#### Linux / macOS

```bash
source .venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```
